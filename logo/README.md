# Логотип SMOTRA

**Надпись на заставке — больше не картинка.** «SMOTRA» теперь живой текст
(Unbounded 900), собранный по буквам скриптом: объём даётся пятью слоями
`drop-shadow` (выдавленный торец), глянец — градиентом с `background-clip:text`,
по которому медленно едет блик, плюс пульсирующее свечение за надписью.
Всё это в `index.html`, в правилах `#splash .s-title` / `.s-glow` и анимациях
`wordIn` / `wordSheen` / `glowPulse`.

Что лежит здесь:

- `smotra-logo.webp` — 512×512, 11 КБ — глянцевая 3D-буква S. В `index.html`
  стоит как иконка приложения (`<link rel="icon">`, 180px, вшита в base64).
- `smotra-logo-512.png` — та же буква в PNG: удобно загрузить иконкой Telegram-бота.
- `smotra-word.webp` — 900×256, 23 КБ — объёмная надпись картинкой. **Не
  используется**: оставлена запасным вариантом, если когда-нибудь захочется
  вернуть надпись растровым леттерингом (в 0.13 она стояла именно так, с
  наложением через `mix-blend-mode:screen`).

Внутри `index.html` картинки лежат в base64, поэтому приложение остаётся одним
файлом и не делает сетевых запросов за иконкой.

# Логотип SMOTRA

Объёмная надпись **SMOTRA** — глянцевый 3D-леттеринг: плотные скруглённые буквы,
белые блески по верхним граням, фиолетовое неоновое свечение, тёмно-синий фон
с диагональными полосами света.

- `smotra-word.webp` — 900×256, 23 КБ — надпись на заставке. Вшита в `index.html`
  как base64 и накладывается на фон через `mix-blend-mode:screen`, поэтому тёмная
  подложка картинки исчезает и видна только сама надпись со свечением.
- `smotra-word-preview.png` — тот же кадр в PNG (для просмотра/исходник).
- `smotra-logo.webp` — 512×512, 11 КБ — иконка приложения: одиночная глянцевая
  буква S (в `index.html` стоит в `<link rel="icon">` в размере 180px).
- `smotra-logo-512.png` — иконка в PNG, для загрузки в иконку Telegram-бота.

Внутри `index.html` всё лежит в base64, поэтому приложение остаётся одним файлом
и не делает сетевых запросов за картинками.

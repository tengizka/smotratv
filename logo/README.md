# Логотип SMOTRA

Глянцевая 3D-буква S в стиле неонового кибер-минимализма: фиолетовый глянец,
белые блески по верхним граням, мягкое свечение в тёмно-синем фоне.

- `smotra-logo.webp` — 512×512, 11 КБ — рабочая версия (вшита в `index.html` как base64
  и на заставке, и в иконке приложения).
- `smotra-logo-512.png` — та же картинка в PNG, для загрузки как иконка Telegram-бота.

Внутри `index.html` логотип лежит двумя копиями base64: 512px на заставку
(`#splash .s-logo`) и 180px в `<link rel="icon">`. Приложение остаётся одним файлом
и не делает лишних сетевых запросов за картинкой.

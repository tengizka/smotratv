# Проверки SMOTRA

Набор автотестов для одиночного `index.html`: статический разбор вёрстки и стилей
плюс живой прогон приложения в jsdom (колода, окна, туториал, клики по кнопкам).

```bash
cd qa
npm i jsdom --no-audit --no-fund
node check.mjs
```

Проверяем ровно то, что уже один раз ломалось: мёртвые кнопки (настройки),
вылезающий за экран туториал, залитая цветом заставка, шторка под открытым окном,
полноэкранный режим и безопасные зоны Telegram, вечные «загрузки» в ленте.

Последний прогон: **160 проверок, 0 падений**.
